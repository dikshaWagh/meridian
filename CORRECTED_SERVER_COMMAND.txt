TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Server won't start:
  • Check model exists: ls ~/models/qwen*.gguf
  • Check llama-server: which llama-server
  • Check port free: lsof -i :8080

Workers don't become healthy:
  • Wait 15 seconds (startup grace period)
  • Check server logs for errors

React UI won't connect:
  • Verify server IP: hostname -I
  • Test connection: curl http://<SERVER_IP>:8080/healthz
  • Check firewall: sudo ufw allow 8080

Can't kill worker:
  • List processes: ps aux | grep llama-server
  • Should see 2 processes
  • Kill second one: kill -9 <PID>
